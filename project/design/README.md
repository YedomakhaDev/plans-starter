## How we work

1. Feedback in your own words: "like it / don't like it / want it like this".
2. Options are shown in Figma or HTML, with an explanation of why.
3. Accepted decisions are recorded right away: values in `tokens.md`, components in `components.md`, the outcome of each step in `concepts.md`.
4. Copy in designs — **approved copy only** (from the project's copy file). If it doesn't fit, change the layout, not the copy. New wording — first a proposal, then a copy update, then the design.
